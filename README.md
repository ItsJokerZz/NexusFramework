## ✨ Overview

**NexusFramework** is designed to provide a unified and extensible interface for interacting with PlayStation 4 and PlayStation 5 systems.

---

## 🚀 Getting Started

Before using the framework, the payload must be injected into the target system.

### 🎮 PlayStation 4
- Use the latest **GoldHEN** (**v2.4b18.8**) with ELF support to inject the payload
- Alternatively, use **John Törnblom’s `elfldr`**
  - ⚠️ May be unstable on older firmware (≤ 9.00)

### 🎮 PlayStation 5
- Send the payload via an `elfldr` socket, or
- Use **etaHEN**’s built-in payload loader (Toolbox)
